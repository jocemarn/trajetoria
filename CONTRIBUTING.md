# Contribuição

Use branches e pull requests. Descreva o problema e o comportamento resultante. Execute as verificações de docs/DESENVOLVIMENTO.md.

Preserve o isolamento municipal e o escopo de cada matrícula. O administrador geral não acessa prontuários municipais. As regras de um plano não devem substituir as de outro.

Não inclua credenciais ou dados reais. Use exemplos fictícios e domínios .invalid. Mantenha chaves de assinatura fora do repositório e dos pacotes.

Atualize CHANGELOG.md e VERSION em cada entrega. A pasta-fonte releases/1.0.0 permanece fixa por compatibilidade.

Nenhuma licença geral de software foi escolhida nesta organização inicial. As licenças de terceiros permanecem aplicáveis.
